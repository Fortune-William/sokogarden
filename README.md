# SokoGarden

Flask + MySQL web application with user authentication (signup/login),
session handling, and image uploads.

## Stack
- Python (Flask), PyMySQL
- MySQL database (`sokogarden`)
- HTML/CSS/JS frontend served from `static/`

## Run locally
1. Create a MySQL database named `sokogarden` and adjust credentials in `app.py`.
2. `python app.py`
3. Open http://127.0.0.1:5000
